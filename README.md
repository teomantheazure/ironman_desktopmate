BRIEF DESCRIPTION
An Iron Man assistant that walks across your desktop and speaks in Tony Stark's style.
The character walks along the bottom of the screen; features such as chat,
voice narration, themes, atmosphere, reminders, and video are accessed via this window.

FEATURES
- Iron Man walking on screen (transparent background, always-on-top).
- Left-click: drag and open menu. Right-click: switch to the next animation.
- Chat: short, witty Tony Stark-style responses. Type "ironman" to close the chat.
- Voice narration: responses are spoken aloud when enabled. Toggle via the menu.
- Languages: Turkish, English, Deutsch, Español, Русский.
- Themes: Stark Gold, Arc Reactor, Stealth Armor, Mark I, Neon Cyberpunk.
- Size: adjustable between 50% and 200%.
- Teleport: select a point on the screen, and the character travels there via a portal effect.
- Summon friend: if Cyclops is in the same folder, he can be summoned to join Iron Man for a conversation.
- Atmosphere: rain, storm & lightning, JARVIS HUD, Arc Reactor pulse,
holiday lights, snow. Includes "Silent" and "Mute Audio" options.
- Live weather: rain, snow, or storms can activate automatically based on your location.
- Reminder: set via the panel or by typing "meeting in 5 minutes" in the chat. 
An alarm sounds and a message appears in a speech bubble when the time is up. - Watch video: Iron Man clips open in the in-app player.
- Background music: Can be toggled on/off via the menu if an x.mp3 file exists in the folder.
- Voice commands: "open notepad", "close calculator", "search Google for ...".

SYSTEM REQUIREMENTS
- Windows 10 or Windows 11 (64-bit).
- Internet: Required for initial license check, chat, weather, audio, and video features.
- Speakers or headphones for audio.
- Administrator privileges not required.
- Antivirus or SmartScreen may trigger a warning upon first launch; this is common
for unsigned desktop applications.

INSTALLATION AND USAGE
1. Extract the downloaded ZIP file to a permanent folder. Do not run the .exe
file in isolation on the desktop; the GIF and MP3 files must remain in the same folder as the .exe.
2. Launch the Iron Man application.
3. The license window appears on first launch. Enter your name and email. 
The computer code will appear automatically.
4. Send the code to the seller via "Send by email" or "Send via WhatsApp". 
Once the license is added, click "Login" using the same name and email. 
The license is tied to this specific computer.
5. The character appears at the bottom of the screen. Left-click to open the menu.
6. Use the "Close" button in the menu to exit the application. FOLDER STRUCTURE

If a GIF is missing, the character may appear blank. If an MP3 is missing, the corresponding sound will not play;
the program will continue to run.
